With the rapid growth of digital data and the increasing use of electronic documents, images, reports, and other digital files, protecting confidential information from unauthorized access has become an important requirement in modern computing systems. Files stored on computers, cloud platforms, removable storage devices, and shared systems may contain sensitive information that should only be accessible to authorized users.

This project focuses on developing a **Secure File Encryption and Decryption System** using symmetric key cryptography. The system allows an authorized user to select a file, provide a secret password, and encrypt the file using **AES-256-GCM**, a secure symmetric encryption algorithm. The encrypted file is stored separately from the original file so that its contents cannot be understood without the correct password. The system also allows users to select an encrypted file and provide the correct password to recover the original file.

For secure key management, the user's password is not directly used as the encryption key. Instead, **PBKDF2-HMAC-SHA256** is used to derive a secure cryptographic key from the password along with a randomly generated salt. A unique nonce is also generated for every encryption operation. AES-256-GCM provides both confidentiality and authentication, allowing the system to detect incorrect passwords or modifications to the encrypted file. If authentication fails, the system reports that decryption was unsuccessful rather than generating an invalid file.

To verify data integrity, the system calculates **SHA-256 hash values** before encryption and after decryption. The hashes are compared to confirm that the recovered file is exactly the same as the original file.

The system supports various file types, including text files, PDF documents, images, and other binary files. Overall, the project demonstrates the practical application of symmetric cryptography to provide **confidentiality, authentication, integrity, secure key management, and reliable file recovery**.
