Encrypt a File

Protect a file with AES-256-GCM and a password.

● AES-256-GCM
Security information

What happens?

  • The original file is not modified.
  • A random salt and nonce are generated.
  • PBKDF2-HMAC-SHA256 derives the AES-256 key.
  • AES-GCM provides confidentiality and authentication.
  • The password is never stored in the encrypted file.
Password → PBKDF2 → AES-256-GCM → Encrypted .enc
Use the same password later to decrypt the .enc file.
