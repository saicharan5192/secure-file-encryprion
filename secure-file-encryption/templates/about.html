Algorithms

Algorithm Information

AES

Advanced Encryption Standard. A symmetric block cipher widely used for protecting data.

AES-256-GCM • RECOMMENDED
DES

Older symmetric block cipher with a 56-bit effective key. It is no longer recommended for modern security.

Blowfish

Symmetric block cipher designed as an alternative to older algorithms.

RC4

Historically used stream cipher that is considered insecure for modern secure applications.

Key Management

Password to Encryption Key

User Password↓PBKDF2-HMAC-SHA256↓Derived AES-256 Key↓AES-256-GCM↓Encrypted File

A random salt is stored as metadata so the same password can derive the correct key later. The derived key itself is never stored.

B.Tech Viva Concepts

Quick Answers

1. What is symmetric cryptography?

It uses the same secret key for encryption and decryption.

2. Why is AES used?

AES is a standardized, efficient symmetric block cipher. This project uses AES-256-GCM for confidentiality plus authentication.

3. What is a block cipher?

A block cipher processes data in fixed-size blocks using a secret key.

4. What is a stream cipher?

A stream cipher encrypts data as a stream of bits or bytes. RC4 is an historical example.

5. What is confidentiality?

Confidentiality means unauthorized people should not be able to read protected information.

6. What is key management?

Key management covers creating, deriving, protecting and using cryptographic keys safely.

7. Why is a salt used?

A random salt makes password-derived keys different even when the same password is reused.

8. Why is an IV/nonce used?

A nonce provides fresh encryption input. AES-GCM requires a unique nonce for each encryption with the same key.

9. What is PBKDF2?

PBKDF2 is a password-based key derivation function that applies repeated HMAC operations to make password guessing more expensive.

10. Why is SHA-256 used?

SHA-256 creates a fixed-size digest used here to verify that the recovered bytes match the original file.

11. What happens with an incorrect password?

AES-GCM authentication fails, so the application rejects the encrypted data and does not create a valid recovered file.

12. Encryption vs hashing?

Encryption is reversible with the correct key. Hashing is designed as a one-way digest and is not used to recover the original data.

13. AES vs DES?

AES is a modern standard with 128/192/256-bit keys; DES uses a 56-bit effective key and is obsolete for modern security.

14. Why is RC4 not recommended?

RC4 has well-known cryptographic weaknesses and should not be selected for modern secure applications.

15. What is AES-GCM?

GCM is an authenticated encryption mode. It provides encryption plus an authentication tag that detects incorrect keys or modified ciphertext/metadata.
