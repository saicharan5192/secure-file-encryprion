Verification

Two layers of protection

  • AES-GCM authentication checks the password and encrypted data.
  • SHA-256 is calculated for the recovered file.
  • The stored original SHA-256 is compared with the recovered hash.
  • A wrong password never produces a valid recovered file.
Wrong password?
Decryption fails with an authentication error. The actual key is never exposed.
